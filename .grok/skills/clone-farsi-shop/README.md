# clone-farsi-shop

Grok skill: clone a store/listing site (any source language) into a Farsi (or other target) Next.js app on Vercel + Neon.

## Install

```
mkdir -p ~/.grok/skills/clone-farsi-shop
# copy SKILL.md into that folder
```

Windows:

```
mkdir $env:USERPROFILE\.grok\skills\clone-farsi-shop
copy SKILL.md $env:USERPROFILE\.grok\skills\clone-farsi-shop\
```

Then in Grok: `/clone-farsi-shop` or `/skills clone-farsi-shop`.

## What you need

Source URL, store name, logo, address, phones, Instagram, domain. Optional: Telegram bot + admin chat IDs, SMS keys, payment merchant, `sourceLang` / `targetLang` (default target `fa`).
